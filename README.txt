국소배기 필요환기량 · 상용덕트 직경 추천 앱

GitHub Pages 경로: https://jiseon74-dev.github.io/1/

배포 방법:
1. 이 ZIP 압축을 풉니다.
2. 저장소의 1 폴더 안 기존 파일을 정리합니다. 저장소 전체는 삭제하지 마세요.
3. 압축을 푼 폴더 안의 index.html, manifest.json, sw.js, icon-192.png, icon-512.png 파일을 저장소의 1/ 폴더 바로 안에 업로드합니다.
4. GitHub Actions/Pages 배포가 성공할 때까지 기다립니다.
5. 휴대폰 크롬에서 https://jiseon74-dev.github.io/1/ 을 열어 앱 설치 또는 홈 화면에 추가를 선택합니다.

기능:
- 부스식/밀폐식, 외부식 일반·플랜지 일반·슬롯·플랜지 슬롯, 캐노피식 필요환기량 계산
- 목표 덕트 반송속도 입력
- 상용 원형 덕트 직경 드롭다운 및 자동 추천 표시
- 선택 직경 기준 실제 반송속도 표시

주의: 상용 규격은 제공된 목록 기준입니다. 추천 규칙은 이론 직경 이하에서 가장 큰 상용 직경을 선택합니다. 실제 반송속도는 목표보다 높을 수 있으며, 압력손실·덕트 길이·엘보·분기·팬 성능은 계산하지 않습니다. 공식 및 규격은 실제 설계 기준에 맞게 확인하세요.
